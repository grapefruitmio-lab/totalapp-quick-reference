# Security and privacy reports

Quick Reference is an experimental alpha.

Please do not publish secrets, private query/session content, personal data, or unsanitized diagnostics in a public issue.

For ordinary reproducible bugs, include the app version, Android version/device, approximate reproduction steps, and sanitized diagnostics where useful.

A dedicated private security-reporting channel has not yet been established. Until one is explicitly published, do not disclose sensitive vulnerability details in a public issue; report only that a private security contact is required.
